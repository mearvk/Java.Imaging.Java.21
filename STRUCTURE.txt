STRUCTURE.txt - Java.Imaging.Java.21
=====================================

Project: Image/Video Metadata Extractor and Photo Organizer
Language: Java 21
Build: IntelliJ IDEA module (no Maven/Gradle)
License: Apache 2.0 (metadata-extractor library by Drew Noakes)
Author: Max Rupplin / MEARVK LLC

OVERVIEW
--------
A photo/video organization tool that:
1. Scans a directory for image and video files
2. Moves .MOV files to a dedicated MOV folder
3. Moves .MP4 files to a dedicated MP4 folder
4. Reads EXIF metadata (date taken) from remaining image files
5. Renames and sorts images chronologically by their EXIF date
6. Copies renamed files and deletes originals

The project incorporates a fork/adaptation of Drew Noakes' metadata-extractor
library (repackaged under com.mearvk) and Adobe's XMP Toolkit.

SUPPORTED FORMATS
-----------------
Images: JPEG, PNG, TIFF, BMP, GIF, PSD, EPS, ICO, PCX, WebP, HEIF/HEIC, RAF
Video:  MP4, MOV/QuickTime, AVI
Audio:  MP3, WAV

PROGRAM FLOW (Main.java)
-------------------------
1. Redirect stdout/stderr to log files
2. Create destination directories for MOV and MP4 files
3. ImageOpener scans initial_directory:
   - .MOV files → copied to MOV folder, originals deleted
   - .MP4 files → copied to MP4 folder, originals deleted
   - Other files → collected for metadata processing
4. ImageSorter processes remaining files:
   - Reads EXIF DateTimeOriginal from each image
   - Renames files to "iPhone_13_file_DD-MM-YYYY.jpg"
   - Sorts by date chronologically
   - Copies with new names, deletes originals
